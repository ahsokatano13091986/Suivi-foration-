FORATION V2 – Ligne 15 / 2302
Décompresser le ZIP. Importer les six fichiers applicatifs à la racine du dépôt GitHub (pas le dossier parent). Settings > Pages > Deploy from a branch > main > / (root) > Save. Ouvrir Visit site dans Chrome, menu > Installer l'application.
Sauvegarder les données de la V1 avant remplacement. La V2 utilise une nouvelle clé locale et ne reprend pas automatiquement les données V1 (format non disponible). Ne pas supprimer les données du navigateur. Export Excel : CSV UTF-8 séparateur point-virgule. PDF : imprimer puis Enregistrer au format PDF. Les icônes fournies sont typographiques provisoires, faute de fichier du logo officiel. Remplacer les deux PNG par des versions officielles avec FORATION dessous, mêmes noms et dimensions, puis changer le nom de cache dans sw.js. Vérifier l'autorisation de publication du logo et ne pas publier de données chantier dans le dépôt public.
